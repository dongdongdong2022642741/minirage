## 三行结论

### a) BM25 vs 向量：向量全面胜出（W3 遗留问题）
向量 recall@10 0.9362 vs BM25 0.5581（+0.3781），recall@5 +0.4179，MRR@10 +0.4125。BM25 仅在 20 个 query（5.1%）上 recall@10 更优。

### b) RRF 平均低于较优单路（W4 验收在全部 query 上 FAIL）
RRF recall@10 0.8835 vs 向量 0.9362（-0.0526）。逐 query：输 66 个、平 320 个、赢 7 个，输的 query 平均亏 0.4599。加权和 0.9005（-0.0357）也未反超。rerank 把 recall@5 从 0.6477 提到 0.7162（+0.0685，86 个 query 受益，另有 39 个下降、268 个持平），recall@10 不变——集合不变只修排序。输入空间无碍（向量 recall@10 已 0.9362），损失来自 RRF 排名平权磨平分数断层，属方法问题，调参方向见下节。

### c) 融合赢输分型：关键词型 vs 语义型
按"单路谁 recall@10 更优"分组：BM25 优势（关键词型）20 个，向量优势（语义型）222 个，平局 151 个。

RRF 输给较优单路的 66 个 query 集中在语义型（RRF recall@10 0.8443 < 向量 0.9653）；关键词型组融合表现：RRF 0.7982 vs BM25 0.9214 vs 向量 0.5117。

## 附：未调参声明与调参方向（问题 F 归因）
- 结论 b 的失败发生在输入空间充足的条件下（向量 recall@10=0.9362），归因于 RRF 机制（排名平权），非 RAW_K 太小。
- 未做参数扫描：RRF_K 调小（如 1~20）可削弱双榜加成、alpha 调大可向向量倾斜，均为候选方向；若调参须在本次全量 393 条上选一次并重新出表，不得用 demo 3 条或本表反推。
